# Balalem.co 🪟✨
### شركة الولاء لستائر - المنصة الرسمية وإدارة الورشة والمعرض

منصة تجارة إلكترونية متكاملة ونظام إدارة وتفصيل ستائر ذكي فائق الفخامة، مخصص لشركة الولاء لستائر (Balalem Co).

---

## 🌟 أبرز مميزات المنصة

- **كتالوج أقمشة ستائر فاخرة:** تصفح واستعراض أنواع الأقمشة الفاخرة (كريب تركي، كتان مسدل، تول مطرز، مخمل ملكي، ستائر زيبرا).
- **حاسبة مقاسات ذكية:** حساب أمتار القماش وتكلفة الخياطة والتفصيل ونسب الزم والكسرات (American Pleat, Wave S-Fold, Eyelet Rings) فورياً.
- **نظام مصادقة وصلاحيات دقيق (RBAC):**
  - **حسابات العملاء (Customer):** حفظ المقاسات، تتبع مراحل التفصيل، سلة المشتريات، وإتمام الطلبات.
  - **حساب مدير النظام (Admin):** محمي ومخصص لإدارة المخزون، ضبط الأسعار، متابعة الطلبيات، وجداول التركيب.
- **لوحة إدارة المعرض والورشة (Showroom POS & Workshop ERP):**
  - تزويد وتعديل الأقمشة مع شريط قوالب سريعة ومعاينة حية 3D.
  - تسجيل طلبيات المعرض المباشرة متعددة النوافذ والغرف وحساب التكلفة تلقائياً.
  - جدول مواعيد تفصيل أسبوعي متكامل (من السبت للخميس) مع شريط استيعاب الطاقة وأزرار واتساب مباشرة.
  - جدول مواعيد التركيب الميداني وتوزيع الفنيين.

## 🚀 التشغيل المحلي (Local Development)

يمكنك تشغيل المتجر محلياً باستخدام سكريبت PowerShell المرفق:

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1 -Port 5500
```

أو عبر تشغيل الملف الدفعي:
```bat
start_store.bat
```

ثم فتح المتصفح على الرابط:
`http://localhost:5500/`

## 📁 هيكلية المشروع

```text
├── assets/images/       # صور المنتجات وخدمات التفصيل الفوتوغرافية
├── css/                 # ملفات التنسيق الفاخرة (main, admin, customer)
├── js/
│   ├── admin.js         # محرك لوحة تحكم المسؤول وإدارة الورشة والمخزون
│   ├── app.js           # المتحكم الرئيسي وإدارة العرض والـ Guard
│   ├── auth.js          # نظام المصادقة والصلاحيات (Admin & Customer)
│   ├── customer.js      # واجهة الزبون، السلة، والحاسبة الذكية
│   └── store.js         # قاعدة البيانات المحلية والمخزون والجدولة
├── index.html           # الصفحة الرئيسية ولوحة التحكم الموحدة
├── server.ps1           # خادم التطوير المحلي
├── netlify.toml         # إعدادات النشر على Netlify
└── vercel.json          # إعدادات النشر على Vercel
```
